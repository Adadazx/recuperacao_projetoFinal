######## Sistema Escolar ############

Este projeto foi desenvolvido em Python como trabalho da disciplina de Lógica de Programação.

O sistema funciona pelo terminal e permite cadastrar, editar, listar e remover alunos, além de cadastrar notas, calcular a média e informar a situação de cada aluno.

############# Como executar #############

1 - Baixe ou clone este repositório.
2 - Abra a pasta do projeto no VS Code.
3 - Execute o arquivo main.py.

 ######## Funcionalidades ############

*Cadastro de alunos;
*Listagem de alunos;
*Edição dos dados dos alunos;
*Remoção de alunos;
*Cadastro de notas;
*Listagem de notas;
*Cálculo automático da média;
*Exibição da situação do aluno.

########## Critérios da situação ###########

*Média maior ou igual a 7,0: Aprovado;
*Média entre 5,0 e 6,9: Recuperação;
*Média menor que 5,0: Reprovado.

######## Armazenamento dos dados ##########

Os dados do sistema são salvos no arquivo dados.json, permitindo que as informações permaneçam salvas mesmo após o programa ser fechado.
